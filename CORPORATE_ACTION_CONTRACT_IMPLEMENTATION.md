# Corporate-action contract implementation

The implementation uses the A–Q specification in `Corporate_action_contract_impact_audit.md`. Initial branch verification found HEAD `d7889749c2a6232e33c5ec3f82468eb593b269e6`, sole parent `5a2ec4181ad897e3d6455c5b7855e0d9830b1768`, and only the audit file added over that parent. No master substitute, merge, deployment, historical database repair, or BandarmoloNY change is part of this work.

`price_contract.py` owns offline registry parsing, typed reference/admission/span outcomes, the existing limit bands, separately named near-limit tolerance, and the existing two-pass analytical tick convention. Result objects require explicit status checks. The tick convention is a model convention and does not establish universal exchange rounding.

`corporate_actions.json` records ENRG's one-session official reference 1065 and SINI's pending boundary with a null reference. Evidence limitations remain explicit. ENRG's original date-only evidence availability and this implementation's actual enrollment time are separate fields. As-of resolution requires both clocks to have elapsed. RAJA has no inferred event record or automatic price/volume correction.

The committed registry certifies no complete action-free universe/date interval. Default legacy input representation is UNKNOWN. Ordinary limit diagnostics remain available under their narrower scope, with an explicit unresolved representation status. Certified economic labels require an explicit actual-price representation and reviewed registry coverage. Unknown calendar, action coverage, source session, or representation withholds results.

The writer preserves actual OHLC and the broker proxy `nlot * 100 * actual_close / 1e9`, including its July 4 cutoff. New event transitions require a resolved reference and an eligible input representation. An initial ordinary source observation without a predecessor may be preserved as `SOURCE_CAPTURE_UNADJUDICATED`; this is not validation of a daily comparison. Changed unresolved transitions refuse before price or broker writes. Identical historical refreshes retain `PRESERVED_UNADJUDICATED` status, and stored violations do not gain predecessor trust by being skipped. An independently referenced event bar can be admitted while its corrupt predecessor remains unchanged and untrusted. Each backfill run pins one registry revision across its tickers.

The dataframe adapter exposes references, previous actual provenance, boundary/segment information, admission, withholding reasons, registry/rule/policy/calendar identity, input representation, and a price snapshot digest. A sole old limit quarantine reason can be superseded in the derived view without rewriting its row. Independent or undocumented reasons remain blocked. Registry changes invalidate the current frame identity.

Forward/lag/gap/extrema labels use the full holding interval and verified calendar. Zero-volume observations do not authorize a daily comparison or bridge a suspension. OO checks include the actual exit open independently of its reference admission and later close. An entry at the event open is after the boundary, so eligible same-session OC arithmetic remains possible. Variable exit and TP/SL helpers check the actual held interval before interpreting a reset as a payoff. DDQN episode identifiers also cut at registry boundaries when an event observation has been removed.

The initial implementation deliberately refuses 111 functions across 47 consumer modules until their source/session/basis/window and persisted-output contracts are migrated. `corporate_action_consumer_routes.json` lists the exact guarded functions. This includes scheduled model, screener outcome, inventory model, book/rule/learning, persisted presentation, and legacy research routes. The guards execute before reads, writes, model fitting, or economic output. Existing frozen artifacts and manifests retain their original meaning. This review state does not enable those routes for production.

Source capture and actual reported flows retain their values. Bagholder implied cost is unavailable while share-basis compatibility is unknown. Screener capture dates and matching HLC do not establish an exchange session. The source adapter requires explicit evidence for session and representation claims.

Integrity monitoring reports boundaries and pending/unresolved references even when contamination is zero, checks for published crossing labels, and checks each price ticker's freshness against the verified calendar. Date offsets in cross-source comparisons remain exploratory.

The offline tests use disposable databases and reconstructed observed anchors. Old tests that required unavailable v0 consumer outputs now require explicit refusal. Retained v0 evidence persistence/validator tests use a test-only fixture pinned to the exact base source hash; they do not create certified v1 price outputs or repin accepted experiments.
